Stock Valuation

Value the on-hand stock by item and company using the active stock and cost records.

Screen: Stock Valuation Report

What it is for

Stock Valuation shows the current value of stock on hand for the selected company and item range.

Before you start

  • Items have a valid stock basis and posted transactions.
  • The date or period for valuation is open and selected correctly.

Step by step

  1. Open Stock Valuation and choose the company.
  2. Select the item set and date range if required.
  3. Run the report and review the value by item.

What happens in the books

This is a read-only valuation report sourced from the stock records and posted values.

Rights

View or report access is normally enough.

Questions and mistakes

  • If values look wrong, check the most recent GRN, movement and adjustment posted to that item.
