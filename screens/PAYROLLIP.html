Interim Payroll

Pays, between the monthly payroll runs, what doesn't wait for them: posted final settlements and approved loans and advances. A batch is approved as set up in Approval Configuration ("Interim payroll"), then gives one bank file for all of it and is marked paid: each settlement and loan gets its own journal, with the batch number as the reference. While in a batch, an item is paid only through it.
