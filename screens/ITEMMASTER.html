Unit of Measure

Conversion factor = how many Base UOM in 1 Alternate UOM. Example: Base = KG, Alternate = BOX, factor = 200 means 1 BOX = 200 KG.

GL Account Linkage

Debited when this item is issued to production (Material Issue), credited back when this item is produced (Production Entry). Not restricted to Expense-type accounts — a Liability or Asset account is equally valid here.

Used when sold directly — e.g. "COGS – Raw Materials", distinct from production consumption.

Used for stock adjustments, scrap, or expiry write-offs.

Every stock transaction posts to the GL automatically using these accounts, picked by transaction type — never chosen per-transaction.
