Approval Configuration

One place for every module's approval rules. Each module can require approval from none, one, or several people depending on the document's value — a level applies whenever the document's amount is at or above that level's own threshold, so giving two levels the same threshold (commonly both 0) means both are always required together, regardless of value. Scope decides what the rule is set per — a Cost Center, Branch, Division, Company, or one single Global rule for the whole system.
