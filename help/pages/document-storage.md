## What it is for

**Document Storage** keeps supporting files attached to ERP records, such as receipts, notes, contracts or payment proofs.

## Before you start

- The relevant record or document is already created.
- The file is in a format the ERP can store and view.

## Step by step

1. Open **Document Storage** and select the relevant company or document.
2. Upload the file or review the stored attachment.
3. Confirm the document is attached to the right record.
4. Save the record and use the attachment for audit or support.

## What happens in the books

The screen stores or retrieves files; it does not create accounting entries by itself.

## Rights

Users with document access or the relevant module rights usually can add and review files.

## Questions and mistakes

- If a file is missing after upload, confirm the record was saved and the attachment belonged to the correct company or document.
