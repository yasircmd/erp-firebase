## What it is for

**Tree Management** is the screen used to arrange the ERP menu and link each module to the correct node, area and user access path.

## Before you start

- The business wants a certain menu layout.
- The module names and areas are known.

## Step by step

1. Open **Tree Management**.
2. Choose the node to move, rename or link.
3. Add the correct screen or module under the menu hierarchy.
4. Save and verify the user sees the correct menu structure.

## What happens in the books

This is a menu and configuration screen, not a financial posting document.

## Rights

Admin users with menu configuration rights should maintain this screen.

## Questions and mistakes

- If a module is missing from the menu, the tree link or rights assignment may not be saved.
