## What it is for

**User Management** is the user configuration screen used to maintain ERP accounts, assign roles and define who can open and use each area.

## Before you start

- The person’s full user details and company assignment are known.
- The roles and permissions for the company are already defined.

## Step by step

1. Open **User Management**.
2. Create or update the ERP user and assign the company.
3. Link the user to the correct roles and rights.
4. Save and test their menu and module access.

## What happens in the books

User Management does not create accounting entries. It controls access to the ERP and the functions available to each user.

## Rights

Only admin users with user-management rights should manage this screen.

## Questions and mistakes

- If a user cannot see a screen, check the company assignment, role and menu rights.
